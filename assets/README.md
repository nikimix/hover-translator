# Значок и картинки для магазина

Исходники значка расширения и картинок страницы Chrome Web Store. Готовые файлы: значки —
`hover-translate/icons/`, картинки магазина — `store/images/en/` и `store/images/ru/`.

## Что здесь

| Файл | Что это |
|---|---|
| `icon.svg` | Значок 128×128: рисунок 96×96 с прозрачными полями 16 px (так советует магазин) |
| `icon-16.svg`, `icon-32.svg`, `icon-48.svg` | Тот же значок для мелких размеров: своя сетка, курсор в 16 и 32 px нарисован по пикселям |
| `store/capture.js` | Съёмка настоящего расширения в Chrome без интерфейса → `store/shots/<lang>/` |
| `store/build.js` | HTML/SVG → PNG: значки, скриншоты, промо-плитки |
| `store/screens.html` | Скриншоты 1280×800 (`?n=1..5&lang=en\|ru`) |
| `store/promo.html` | Промо-плитки 440×280 и 1400×560 (`?size=small\|marquee&lang=en\|ru`) |
| `store/texts.js` | Подписи на картинках (английский и русский) |
| `store/demo/` | Демонстрационная статья: испанская (для английских картинок) и английская (для русских) |
| `store/shots/` | Снимки, сделанные `capture.js`, и координаты для курсора (`layout.js`) |

## Как перегенерировать

Нужны Node.js 18+ и Google Chrome 138+ (`google-chrome` в PATH). Пакеты npm не нужны.

```bash
# 1. Значок: после правки assets/icon*.svg
node assets/store/build.js icons            # → hover-translate/icons/16, 32, 48, 128.png

# 2. Снимки настоящего расширения (если менялся интерфейс или демо-статья)
node assets/store/capture.js en ru          # → assets/store/shots/en, shots/ru
#   --profile DIR — профиль Chrome, где языковые модели уже скачаны; без него модели
#   скачиваются заново (1–5 минут, нужен интернет)
#   Проблемное состояние в кадре (ошибка, «нужно скачать», нет кнопки) — строка «!» и код выхода 2

# 3. Картинки магазина (если менялись снимки, подписи или раскладка)
node assets/store/build.js screens promo    # → store/images/<lang>/screenshot-1..5.png, promo-*.png
```

Без аргументов `build.js` делает всё. Переменная `HT_TMP` задаёт папку для временных файлов `capture.js` и
`build.js` (по умолчанию — системная; копия расширения и профиль Chrome — сотни МБ, на маленьком `/tmp` не держать).

## На что смотреть после перегенерации

- Цвета — как у интерфейса: акцент `#2563eb`, янтарь `#ffcf4a` — «переведённое». Плитка значка — лёгкий
  градиент `#3070f1 → #1a56e5` (в середине `#2563eb`, как `logo()` в окне и настройках), обводка курсора
  `#0b1f4d`. Фон скриншотов — синий градиент (`store.css`), промо-плиток — глубже (`promo.html`), иначе значок
  на плитке сливается с фоном.

- Скриншоты — 1280×800, промо — 440×280 и 1400×560, PNG без прозрачности (фон страниц непрозрачный).
- Подписи крупные: в магазине скриншоты уменьшаются до 640×400, плитка — вдвое.
- Шрифты: подписи — Ubuntu Sans, интерфейс и статья — Noto Sans / Noto Serif (системные шрифты Linux).
  На другой системе подставятся замены — проверьте переносы строк глазами.
- Перевод в статье делает встроенный переводчик Chrome. Демо-текст подобран так, чтобы его перевод
  читался чисто (короткие куски с выделением и ссылкой — с начала фразы); если поменять текст, проверьте
  перевод на снимках.
- Промо-плитки в магазине не переводятся на языки: загружается одна на все языки — английская
  (`store/images/en/`). Русские — на случай, если понадобятся отдельно. Скриншоты загружаются для
  каждого языка свои.
