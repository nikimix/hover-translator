# Cursor Translate

Chrome-расширение (Manifest V3): наводишь курсор на текстовый элемент (или жмёшь
выбранную клавишу) — его текст переводится через DeepL и **заменяется на месте**. Исходный язык определяется автоматически
(DeepL auto-detect), целевой — настраивается в popup. Уводишь курсор — возвращается оригинал.

## Как устроено

- **`background.js`** (service worker) — обращается к DeepL и к LLM (ключи не видны странице, нет
  CORS), умеет `source_lang`, `formality` и список «не переводить» (через `ignore_tags`).
  Переводы кэшируются в памяти (L1, до 1000 записей, FIFO), в **`storage.session`** (L2,
  переживает перезапуск service worker) и в **`storage.local`** (L3, переживает перезапуск
  браузера, TTL 14 дней, бюджет ~4 МБ — квота `storage.local` общая с настройками). На `429`/`5xx` —
  **ретрай с backoff** (учитывая `Retry-After`), одинаково для DeepL и LLM. Батчи режутся и по
  количеству текстов, и по фактическому объёму запроса. Считает **статистику расхода** (символов
  переведено / попаданий кэша) и держит **бюджет расхода на сайт** — страница не может бесконечно
  тратить ключ движением курсора.
- **`content.js`** — ловит наведение/клавишу, выбирает ближайший строчный контейнер с текстом,
  показывает перевод одним из двух способов (**способ показа**): **замена на месте** — меняются
  только значения текстовых узлов, поэтому теги `<b>/<a>/<span>`, обработчики событий и структура
  DOM сохраняются; или **поповер** — плавающая карточка с переводом, оригинал на странице
  остаётся. Опционально — **бейдж исходного языка** (`EN → RU`). Текст, **уже на целевом языке**,
  не отправляется (on-device `LanguageDetector`); исходный язык можно и **задать вручную**.
  Поддержаны движки: **DeepL**, **LLM** (OpenAI/Anthropic — контекстный перевод), **встроенный
  Chrome Translator** (on-device, без сети) и **авто** (DeepL → встроенный при сбое).
  «Перевести страницу» переводит **сначала видимое**, остальное — по мере прокрутки
  (IntersectionObserver). На странице есть **мини-HUD** смены целевого языка — его можно
  перетащить за ручку. Собственный UI (карточка и HUD) живёт в **shadow root**, поэтому CSS
  страницы его не ломает.
- **`shared.js`** — единственное место для данных, общих всем трём контекстам: таблицы языков
  (целевые коды, исходные коды, английские имена для промпта LLM), таблица движков (куда уходит
  запрос, какой нужен ключ, что входит в ключ кэша, есть ли фолбэк) и значения настроек по
  умолчанию. Подключается в content_scripts, через `importScripts` и в popup — иначе каждый такой
  список живёт в трёх копиях и они расходятся.
- **`popup.html/js/css`** — настройки: ключ (с показом/скрытием и кнопкой-проверкой ✓),
  остаток лимита символов DeepL, целевой язык + чипы недавних языков, способ активации,
  задержка, настройки отображения перевода, а также кнопки **«Перевести страницу»** и **«Сбросить»**.
  Команды адресуются только верхнему фрейму вкладки.

## Установка (загрузка распакованного расширения)

1. Получи бесплатный ключ DeepL API на <https://www.deepl.com/pro-api> (нужен аккаунт;
   free-ключ оканчивается на `:fx`, лимит 500 000 символов/мес). Платный ключ тоже подойдёт —
   эндпоинт выбирается автоматически по суффиксу ключа.
2. Открой `chrome://extensions`, включи **Режим разработчика** (справа вверху).
3. Нажми **«Загрузить распакованное расширение»** и выбери папку `hover-translate`.
4. Кликни иконку расширения → вставь ключ DeepL → нажми иконку **✓** (проверка ключа).
   При успехе блок свернётся с галочкой, ниже покажется остаток лимита символов. Выбери язык и способ активации.
5. Открой любую страницу и наведи курсор на текст.

## Настройки

| Параметр | Описание |
|---|---|
| Панель иконок сверху | ⏻ — вкл/выкл перевода (подсвечена синим, когда включено); 🌐 — перевести всю страницу (сначала видимое, дальше по прокрутке); ▱ — показать/скрыть **мини-HUD** смены языка на странице (подсвечена синим, пока панель показана; панель перетаскивается за ручку ⠿); ↺ — сбросить все переводы к оригиналу. У каждой иконки всплывающая подсказка. |
| Движок перевода | `DeepL` (нужен ключ), `DeepL → встроенный` (фолбэк при сбое DeepL), `Встроенный Chrome` (on-device, без сети и ключа, Chrome 138+, desktop) или `LLM (OpenAI/Anthropic)` — контекстный перевод (лучше для идиом, но платно и медленнее). Поля, не нужные выбранному движку, скрываются. |
| API-ключ DeepL | Free или Pro; эндпоинт определяется по суффиксу `:fx`. Кнопка-глаз справа показывает/скрывает ключ. |
| LLM-движок | Провайдер (OpenAI / Anthropic), API-ключ (кнопка-проверка ✓) и модель. Ключ хранится локально, виден только service worker. Перевод сохраняет HTML-теги. |
| Очистить кэш | Удаляет сохранённые переводы из кэша (память + `storage.session` + `storage.local`) и **обнуляет статистику расхода**. Не влияет на уже показанные переводы — для отката используйте ↺. Помогает и когда `storage.local` переполнен и настройки перестали сохраняться. |
| Статистика | Сколько символов переведено (промахи кэша) и сколько попаданий кэша / сэкономлено символов. Обнуляется кнопкой «Очистить кэш». |
| Переводить на | Целевой язык (по умолчанию русский). Под списком — чипы недавно выбранных языков для быстрого переключения. |
| Исходный язык | `Определять автоматически` (DeepL/детектор) или фиксированный язык источника — прокидывается в `source_lang` (DeepL) и в подсказку LLM. |
| Тон (formality) | Для DeepL: `По умолчанию` / `Более формально` / `Менее формально`. Поддерживается не всеми языками — для остальных игнорируется. |
| Активация перевода | `При наведении (по задержке)` — переводит после задержки курсора. `Shift/Alt/Ctrl + наведение` — переводит только при удержании выбранной клавиши. Защищает квоту от случайных наведений. Жесты колеса с тем же модификатором расширение не перехватывает: `Shift + колесо` (горизонтальная прокрутка) и `Ctrl + колесо` (масштаб) остаются прокруткой и зумом, перевод при этом не запускается. |
| Задержка наведения | Только для режима «по задержке»: сколько держать курсор на элементе перед переводом (антидребезг). |
| Способ показа | `Замена на месте` или `Поповер` (оригинал на странице остаётся; длинный перевод в карточке прокручивается). Поповер работает только при наведении — «перевести страницу» всегда использует замену на месте. |
| Бейдж исходного языка | Показывать ли метку `EN → RU` рядом с переводом. |
| Подсветка | `Адаптивная` (сама подстраивается под тёмные/светлые сайты), `Своя` (свой фон, прозрачность и граница) или `Без подсветки`. |
| Не переводить | Список терминов/брендов (через запятую или с новой строки), которые движок оставит как есть. Порядок ввода не важен: более длинные термины применяются первыми, поэтому `Node.js` не распадается на `Node` + `.js`. Работает для DeepL и LLM; встроенный Chrome-движок не поддерживает. |

## Ограничения и заметки

- **Изменения настроек применяются к уже показанным переводам сразу:** подсветка — мгновенно;
  способ показа и бейдж — перерисовкой из сохранённого перевода (без сети); язык/движок/
  формальность/исключения — перезапросом перевода (с дебаунсом и кэшем). Выключение перевода (⏻)
  откатывает все переводы к оригиналу.
- Переводится **ближайший строчный контейнер** под курсором (абзац/строка может содержать
  вложенные `<b>/<a>/<span>` — берётся целиком). Крупные блоки с вложенными блочными
  элементами (несколько `<p>`, списки целиком и т.п.) пропускаются. Лимит — 2000 символов.
- В режиме клавиши перевод **залипает**: повторное нажатие клавиши на том же элементе
  возвращает оригинал (исходная разметка восстанавливается). В режиме задержки перевод —
  это превью: возвращается, когда курсор уходит с элемента. Переход курсора на вложенный
  `<b>/<a>/<span>` внутри того же элемента уходом не считается.
- Модификатор нужен не только нам: `Shift + колесо` — это горизонтальная прокрутка, `Ctrl + колесо` —
  масштаб страницы. Поэтому нажатие клавиши-триггера срабатывает с задержкой ~160 мс и отменяется,
  если пришло колесо; пока идёт такой жест (и полсекунды после) зажатая клавиша переводом не
  считается. Прокрутка карусели или широкой таблицы с зажатым Shift больше не переводит всё, что
  проехало под курсором. Если конфликт мешает совсем — выберите `Alt + наведение` (Chrome не
  использует Alt+колесо) или режим задержки.
- Ответ движка **никогда не вставляется как HTML**: он раскодируется в чистый текст (`DOMParser`),
  поэтому prompt-инъекция в переводе не может ничего исполнить на странице. По той же причине
  в поповере перевод показывается без разметки.
- Есть **бюджет расхода на сайт в минуту** (отдельный для наведения и для перевода страницы):
  враждебная страница не сможет выесть квоту ключа, подсовывая новый текст под курсор. При
  исчерпании появляется уведомление — обычная работа в лимиты не упирается.
- DeepL Free имеет месячную квоту символов и лимит запросов — помогают **кэш** и **dwell**.
  Для экономии используй режим клавиши (Shift/Alt/Ctrl). Остаток лимита виден в popup.
- Работает на десктопе, минимальная версия — **Chrome 102** (`storage.session`); встроенному
  движку нужен Chrome 138+. На страницах вроде `chrome://`, Web Store и внутри некоторых
  iframe content-скрипты не запускаются — это ограничение Chrome.
- Целевой `EN` у DeepL задаётся как `EN-US`/`EN-GB` (уже учтено в списке языков).

## Возможные доработки

- Перевод выделенного текста + пункт в контекстном меню; глобальный хоткей вкл/выкл (`chrome.commands`).
- Вкл/выкл по сайтам (белый/чёрный список), авто-перевод выбранных доменов при загрузке.
- `Esc` — откатить все переводы; озвучивание (TTS) и история переводов с экспортом в Anki.
- DeepL glossary вместо простого списка «не переводить».
