Hover Translator

A browser extension for Google Chrome™: point at any text and press Shift — it’s translated right on the page, with links and layout kept. Press again for the original; Esc brings back the whole page.

  • Works right after installing: no account and no key. By default it uses the translator built into Chrome, which runs on your computer.
  • Optional: DeepL or AI (OpenAI, Anthropic) with your own key — text is sent only after you agree.
  • No server of its own, no analytics, no ads. Open source.

Переводчик при наведении

Расширение для Google Chrome™: наведите курсор на текст и нажмите Shift — он переведётся прямо на странице, ссылки и вёрстка останутся на месте. Ещё раз — вернётся оригинал, Esc — вся страница.

  • Работает сразу после установки: без учётной записи и без ключа. По умолчанию переводит встроенный в Chrome переводчик прямо на компьютере.
  • По желанию — DeepL или ИИ (OpenAI, Anthropic) по своему ключу: текст уходит туда только после вашего согласия.
  • Нет своего сервера, сбора сведений о пользователях и рекламы. Исходный код открыт.
